# Advanced Calculator Tool

## Overview
A world-class calculator application featuring both simple and scientific modes, designed to be one of the best calculators in the market.

## Features

### 🧮 Simple Calculator
- Basic arithmetic operations (+, -, ×, ÷)
- Decimal support
- Clear and backspace functions
- Sign change (±)
- Clean, intuitive interface

### 🔬 Scientific Calculator
- **Trigonometric Functions**: sin, cos, tan, asin, acos, atan
- **Hyperbolic Functions**: sinh, cosh, tanh, asinh, acosh, atanh
- **Logarithmic Functions**: log (base 10), ln (natural log), log2 (base 2)
- **Power & Root Functions**: x^y, √x, ∛x
- **Advanced Functions**: |x|, floor, ceil, round, factorial, random
- **Constants**: π (pi), e (Euler's number)
- **Memory Functions**: MC, MR, MS, M+, M-
- **Angle Modes**: Degrees and Radians

### 🎯 Advanced Features
- **Calculation History**: Store and view up to 100 recent calculations
- **Keyboard Support**: Full keyboard input with shortcuts
- **Copy to Clipboard**: Easy result copying
- **Theme Support**: Light, dark, and auto modes
- **Persistent Storage**: Saves history, memory, and settings
- **Error Handling**: Graceful error management for invalid operations
- **Responsive Design**: Works perfectly on all device sizes

### ⌨️ Keyboard Shortcuts
- **Numbers**: 0-9
- **Operators**: +, -, *, /
- **Clear**: C, Escape
- **Backspace**: Backspace, ⌫
- **Equals**: Enter, =
- **Decimal**: ., ,
- **Power**: ^, **
- **Constants**: p (π), e

### 🎨 User Interface
- **Beautiful Design**: Modern, clean interface with gradient backgrounds
- **Intuitive Layout**: Easy-to-use button arrangement
- **Visual Feedback**: Clear display with proper formatting
- **Responsive**: Optimized for desktop, tablet, and mobile
- **Accessibility**: Keyboard navigation and screen reader friendly

### 💾 Data Persistence
- **Local Storage**: All data saved locally in browser
- **History**: Maintains calculation history across sessions
- **Memory**: Preserves memory values
- **Settings**: Saves theme and angle mode preferences

## Technical Implementation

### Architecture
- Built with Next.js 14 and React 18
- TypeScript for type safety
- Tailwind CSS for styling
- Lucide React for icons
- Custom hooks for state management

### State Management
- Complex state management for calculator operations
- Persistent storage with localStorage
- Real-time UI updates
- Error boundary handling

### Performance
- Optimized rendering with useCallback hooks
- Efficient memory management
- Smooth animations and transitions
- Fast calculation processing

## Usage

### Simple Mode
1. Click number buttons to input values
2. Use operator buttons (+, -, ×, ÷) for calculations
3. Press = or Enter to get results
4. Use C to clear, ⌫ for backspace

### Scientific Mode
1. Switch to Scientific tab
2. Use advanced functions like sin, cos, log, etc.
3. Toggle between degrees and radians
4. Use memory functions for complex calculations
5. Access calculation history

### Keyboard Usage
- Use your keyboard for faster input
- All standard calculator keys supported
- Special shortcuts for constants and functions
